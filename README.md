## Запуск

Просто откройте `index.html` в браузере (карточки команды возьмутся из запасных данных в `main.js`).

Через Docker (карточки читаются из `data/team.json`):

```bash
docker build -t api-molodtsy .
docker run -p 8080:80 api-molodtsy
```

Откройте http://localhost:8080

## Как заменить фото

Положите настоящие фото в `assets/` под теми же именами (`anna.png`, `margarita.png`, `roman.png`, `ekaterina.png`, `adelina.png`), лучше в пропорции 3:4. Чёрно-белый эффект добавляется CSS автоматически.
